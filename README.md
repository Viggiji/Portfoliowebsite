## ✨ Features

- 🎥 **Cinematic Preloader** – An engaging 7-8 second entrance that sets the tone before delving into the portfolio content.
- 🌌 **Immersive 3D Elements** – Interactive background graphics and geometric shapes using `@react-three/fiber` and `@react-three/drei`.
- 🪄 **Dynamic Animations** – Exceptionally smooth scroll effects, hover-scramble text, and micro-interactions powered by **Framer Motion** and **GSAP**.
- 🧩 **High-Fidelity Components** – Integration of specialized **ReactBits** components like Fuzzy Text, Bounce Cards, and an interactive App Dock for a brutalist aesthetic.
- 🎵 **Integrated Background Music** – Features a curated background playlist (Polyphia, Marcin) to enhance the browsing atmosphere.
- 📱 **Fully Responsive** – Optimized with **Tailwind CSS** to look stunning and function seamlessly on both desktop and mobile devices.
- ⚙️ **Single Source of Truth** – Out-of-the-box clean architecture; all personal data, content, and links are dynamically rendered from a centralized file.

## 🧑‍💻 Setup Instructions

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed along with `npm` or `yarn`.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Viggiji/Portfoliowebsite.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Portfoliowebsite
   ```

3. **Install the dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
   *Your app should now be running on `http://localhost:5173`.*

5. **Build for production**
   ```bash
   npm run build
   ```

## 🎨 Customization

Personalizing this portfolio is straightforward. Open the `src/data.js` file — it acts as the **single source of truth** for the entire website.

- **Profile & Resume:** Update the `PERSON` and `EDUCATION` objects with your details.
- **Social Links:** Update the `SOCIALS` array.
- **Skills:** Modify the lists inside the `SKILLS` object.
- **Assets:** Replace images like `profpic.jpg` located in the `public` directory.

*⚠️ **Note:** Ensure you replace the placeholder `YOUR_EMAIL_HERE` with your actual email string before deploying.*
